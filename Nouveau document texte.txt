Créer un schéma professionnel de l’architecture.

Architecture :

class resnet_feature_extractor(torch.nn.Module):
- Extraction layer2
- Extraction layer3
- Average Pooling 3×3
- Concaténation des features
- Flatten
- Memory Bank

Dimensions :
- layer2 = 512
- layer3 = 1024
- concat = 1536

Méthode :
- ResNet50 pretrained ImageNet
- Memory Bank classique
- Réduction à 10% des patches
- Distance euclidienne minimale
- Seuil = moyenne + 2×écart-type

Input Image

→ Distance Computation
